      Setup guide (Windows laptop)

      1. Buy an RTL-SDR Blog V4 dongle (~$40 CAD) with the dipole antenna kit.
      2. Driver: plug it in, run Zadig, pick “Bulk-In, Interface (Interface 0)”, install WinUSB.
      3. Quickest listen: install SDR++ on the laptop and tune directly.
      4. Raw IQ server: run rtl_tcp -a 0.0.0.0 -p 1234, choose rtl_tcp above with 127.0.0.1:1234, press probe. A real dongle answers with an RTL0 header + tuner name.
      5. Listen on the iPhone too: run OpenWebRX (Docker: docker run -d -p 8073:8073 --device /dev/bus/usb jketterl/openwebrx on a Linux box / Raspberry Pi), then set its URL above. It then appears in this app's viewer on any device on your Wi-Fi.

      Legal boundaries (Canada)

      • Everything here is intentionally published by its owner: public SDR directories, government traffic cameras, NOAA/NASA imagery, ADS-B aggregators.
      • This app does not scan for, discover or connect to unsecured cameras or devices. Accessing a system you aren't authorized to use is an offence (Criminal Code s.342.1) even with no password involved.
      • Radio: receiving open broadcasts, amateur, aviation and weather traffic is fine. Under the Radiocommunication Act you must not divulge or use private radiocommunications you happen to hear, and must not decode encrypted signals.
      • Respect each receiver owner's time limits and slot counts — they share their hardware for free.
